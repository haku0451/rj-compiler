# RJ Language Specification

## Overview

RJはJVM向けの静的型付けプログラミング言語です。

設計目標:

* Pythonのような書きやすさ
* KotlinレベルのJVM互換性
* Rustライクな式指向
* Java 21バイトコード生成
* Gradleベースの開発体験
* 初心者にも理解しやすい構文

---

# Basic Information

| Item                | Value    |
| ------------------- | -------- |
| Language Name       | RJ       |
| File Extension      | .rj      |
| Compiler            | rjc      |
| Target Platform     | JVM      |
| Target Java Version | Java 21  |
| Build Tool          | Gradle   |
| Package Declaration | Required |

---

# Project Structure

```text
project/
├─ build.gradle.kts
├─ settings.gradle.kts
└─ src
   ├─ main
   │  └─ rj
   └─ test
      └─ rj
```

RJ独自の設定ファイルは作成しない。

設定はすべてGradleで管理する。

---

# Package

package宣言は必須。

```rj
package com.example.app
```

ディレクトリ構造との一致が必要。

例:

```text
src/main/rj/com/example/app/Main.rj
```

```rj
package com.example.app
```

不一致の場合はコンパイルエラー。

# Imports

通常のimport

```rj
import java.time.LocalDateTime
```

エイリアス

```rj
import java.time.LocalDateTime as Time
```

ワイルドカード

```rj
import java.util.*
```

循環参照は禁止。

# Functions

```rj
def add(a: int, b: int) -> int {
    a + b
}
```

最後の式が戻り値になる。

```rj
def value() -> int {
    let x = 5
    x
}
```

明示的returnも使用可能。

```rj
return 5
```

# Classes

```rj
class User {

    let name: str
    let age: int

    def __init__(name: str, age: int) {
        self.name = name
        self.age = age
    }
}
```

フィールド宣言はクラス先頭のみ許可。

## Match Expression

```rj
match color {

    case Color.Red {
        print("red")
    }

    case Color.Green {
        print("green")
    }

    case _ {
        print("other")
    }
}
```

式として利用可能。

```rj
let value = match color {

    case Color.Red {
        "red"
    }

    case _ {
        "other"
    }
}
```

# File Naming Rules

ファイル名とクラス名は一致必須。

例:

```text
User.rj
```

```rj
class User {
}
```

許可。

```text
User.rj
```

```rj
class Account {
}
```

コンパイルエラー。

# Error System

RJコンパイラはエラーコードを必ず出力する。

エラーメッセージは多言語対応。

デフォルトはOSロケールを使用する。

例:

```text
E010: package宣言が必要です
```

英語環境:

```text
E010: package declaration is required
```

---

# Error Format

```text
[ErrorCode]: Message

Location:
  File
  Line
  Column

Hint:
  Suggested Fix
```

例:

```text

  src/main/rj/Main.rj:1:1
```

# Common Errors

## E010

package宣言が存在しない。

例:

```rj
def main() {
}
```

出力:

```text
E010: package宣言が必要です

Hint:
package com.example
```

---

## E020

未知のキーワード。

例:

```rj
from java.util import List
```

出力:

```text
E020: 未知のキーワード 'from'

Hint:
import java.util.List
```

---

## E101

ファイル名とクラス名が一致しない。

例:

```text
User.rj
```

```rj
class Account {
}
```

出力:

```text
E101: ファイル名とクラス名が一致していません

File:
User.rj

Class:
Account
```

---

## E102

パッケージ構造がディレクトリ構造と一致しない。

例:

```text
src/main/rj/com/example/User.rj
```

```rj
package com.test
```

出力:

```text
E102: パッケージ構造が一致しません

Expected:
com.example

Found:
com.test
```

---

## E110

フィールドがクラス先頭以外に定義された。

例:

```rj
class User {

    def hello() {
    }

    let name: str
}
```

出力:

```text
E110: フィールドはクラス先頭に定義してください
```

---

## E120

循環importを検出。

例:

```text
A -> B -> A
```

出力:

```text
E120: 循環参照を検出しました

Path:
A -> B -> A
```

---

## E130

newキーワードは存在しない。

例:

```rj
new User()
```

出力:

```text
E130: 'new' キーワードは存在しません

Hint:
User()
```
